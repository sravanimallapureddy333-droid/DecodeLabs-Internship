# 🔐 Project 3 – Cloud Connected Security Node

## 📌 Objective

To detect nearby objects using an HC-SR04 ultrasonic sensor and send real-time distance data to Adafruit IO using ESP32 over Wi-Fi for remote monitoring.

## 🛠️ Components Used

- ESP32
- HC-SR04 Ultrasonic Sensor
- Wi-Fi
- Adafruit IO Cloud Platform
- Arduino IDE
- Wokwi Simulator

## ✨ Features

- Real-Time Distance Measurement
- Wi-Fi Connectivity
- Adafruit IO Cloud Integration
- Remote Distance Monitoring
- Intruder Detection Logic
- Serial Monitor Output
- Cloud Dashboard Visualization

## 🚀 Working

The HC-SR04 ultrasonic sensor continuously measures the distance of nearby objects. The ESP32 processes the sensor readings and sends the distance data to the Adafruit IO cloud platform over Wi-Fi. The data is displayed on the cloud dashboard for real-time remote monitoring while also being shown on the Serial Monitor.
