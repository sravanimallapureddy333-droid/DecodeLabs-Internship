# 🌡️ Project 1 – Smart Environmental Monitor

## 📌 Objective

To monitor temperature and humidity using an ESP32 and DHT22 sensor.

## 🛠️ Components Used

- ESP32
- DHT22 Temperature & Humidity Sensor
- Arduino IDE
- Wokwi Simulator

## ✨ Features

- Real-time Temperature Monitoring
- Real-time Humidity Monitoring
- Temperature Status Detection (Hot / Normal / Cold)
- Humidity Status Detection (Dry / Good / Humid)
- Minimum & Maximum Value Tracking
- Serial Monitor Output
- Non-Blocking Programming using `millis()`

## 🚀 Working

The DHT22 sensor continuously measures temperature and humidity. The ESP32 processes the sensor data and displays the readings through the Serial Monitor. Based on predefined thresholds, the system classifies the environmental conditions and keeps track of minimum and maximum values.
